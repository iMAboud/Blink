# Blink 

<img width="100" height="100" alt="Blink" src="https://i.imgur.com/yTYkm5A.png" />

A lightweight, debloated screen capture and productivity tool for Windows.

## Features

<div align="left" style="display: inline-block;">

- **Screen Capture**: Fast region, active window, active monitor, or fullscreen capture.
- **GIF Recording**: Record short screen clips and animated GIFs.
- **OCR**: Extract text directly from selected screen regions.
- **Pin to Screen**: Float captured snippets or images on top of other windows.
- **QR Codes**: Fast QR code scanning and generation.
